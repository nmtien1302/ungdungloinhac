# Font

Ứng dụng dùng font **Archivo** (Google Fonts, miễn phí) — gần giống font Delight trong ảnh mẫu.

Nếu bạn có bản quyền font **Delight**, đặt file biến thể vào đây với tên:

    fonts/Delight-Variable.woff2

CSS đã khai báo sẵn `@font-face` cho "Delight" và ưu tiên dùng nó trước Archivo.
Nếu chỉ có file .otf/.ttf, đổi tên tương ứng rồi sửa `src` trong `css/styles.css`.
